# サイト再設計（2026-10）— 第一原理からの設計メモ

## 1. 読者（Audience）

| 読者 | 状況 | 求めるもの |
| --- | --- | --- |
| 日本のエンジニア（SIer・事業会社・フリーランス） | FDE 的な仕事を任された / 目指している | 進め方、実装パターン、成果物の型、市場価値 |
| PM・事業部の推進担当 | AI 導入を現場で進める責任がある | 工程ごとのやること、業界別の注意点、合意の作り方 |
| 企業（採用・導入判断をする側） | FDE を採用・外注したい | 役割定義、採用ガイド、市場単価、大手の動向 |

## 2. 来訪目的（Jobs to be done）

1. **FDE を理解する** — 役割・スキル・他職種との違い
2. **案件の進め方を学ぶ** — 6 ステップと工程別のやること
3. **実装パターンを選ぶ** — どの型をいつ使い、何をチェックするか
4. **業界別の進め方を見る** — 領域のユースケースと領域×工程の注意点
5. **成果物を作る** — そのまま使えるテンプレート
6. **市場と業界の動きを追う** — 案件数・単価、大手 IT の AI 施策、規制

旧サイトはホームが「市場データのダッシュボード」中心で、2〜5 の入口が埋もれていた。

## 3. 情報設計（IA）

```
ホーム（目的から探す 6 カード → 6 ステップ図 → 今週の市場サマリー → 知識グラフ）
├─ FDE とは        /guide/what-is-fde
├─ 進め方          /guide（6 ステップ）・/process（工程）
├─ パターン        /patterns（各ページ末尾に導入チェックリスト・関連リスク）
├─ 領域別          /domains・/matrix（領域×工程の交点）
├─ 市場・動向  NEW /market（需要データ・魚骨図・単価分布）→ /vendors・/references/market-demand・ai-regulation
├─ テンプレート NEW /references/deliverables
├─ 資料（ドロップダウン）/references/*
└─ 検索       NEW /search（静的エクスポートで動くクライアント全文検索）
```

- **URL は一切変更しない**（新規追加のみ）。旧 `/guide/what-is-pde/` はリダイレクト。
- ナビ定義は `apps/web/lib/site.ts` に一元化（ヘッダー・モバイルメニュー・ホームのカードが参照）。

## 4. ナビゲーション

- デスクトップ: 目的順の主ナビ 6 項目 + 「資料」ドロップダウン + 検索 + GitHub
- スマホ（≤860px）: ハンバーガー（`<details>`、JS 不要）に集約

## 5. ページテンプレート

| 種別 | 構成 |
| --- | --- |
| ハブ（/market など） | `PageHeader`（kicker / title / lead）→ カードグリッド → 本体 |
| 記事（ガイド・パターン・資料） | 見出し → 要約 → 目次 → 本文 → **チェックリスト** → **落とし穴** → 出典 → 更新情報 |
| 交点（領域×工程） | 要点 → 領域特有の注意（出典付き）→ 成果物チェックリスト → よくある落とし穴 |

## 6. コンテンツ方針

- 事実（統計・企業の動き・法令・市場の数値）は**必ず一次情報の出典リンク**を付ける。推測の数値・架空の事例・引用は書かない。
- 実務の助言（手順・チェック項目）は出典不要だが、法令・ガイドラインに触れる箇所は出典を付ける。

## 7. 実装メモ

- CSS: `app/globals.css` を `styles/*.css` に責務別分割（読み込み順＝カスケード順）。リデザイン分は `styles/redesign.css`。
- 知識グラフ: データ・幾何ユーティリティを `lib/knowledge-graph.ts` に分離。
- 今後: 多言語（en / zh）は `content/{locale}` と `lib/site.ts` の辞書化で対応予定。
